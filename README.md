# ExploreUK - Landing Page

## About the Project

ExploreUK is a responsive landing page created as part of the
Oasis Infobyte Web Development Internship.

The website promotes Uttarakhand as a travel destination and
highlights some popular places.

## Technologies Used

- HTML5
- CSS3
- Flexbox
- CSS Grid
- Media Queries

## Features

- Sticky navigation bar
- Hero section
- Call-to-action button
- Popular places section
- About section
- Contact section
- Footer with social links
- Responsive design for mobile and desktop
